## Proyecto argentino 🇦🇷 / Argentine project 🇦🇷

**ES:** SanLean es un proyecto web argentino independiente creado y desarrollado por **SanLean**, centrado en herramientas y experiencias para la comunidad de Dead by Daylight.

**EN:** SanLean is an independent Argentine web project created and developed by **SanLean**, focused on tools and experiences for the Dead by Daylight community.

**Sitio oficial / Official website:** https://sanlean17.github.io/

## Inspiración y referencias / Inspiration and references

### DBD Perk Slot Machine — 3stadt

**ES:** El concepto de una ruleta/slot machine de perks tomó inspiración y referencia conceptual de **DBD Perk Slot Machine**, proyecto de **3stadt**. La implementación utilizada por SanLean fue desarrollada para este proyecto; este crédito reconoce la inspiración conceptual y no pretende indicar que el código fuente de 3stadt forme parte del código original desarrollado para SanLean.

**EN:** The perk roulette/slot-machine concept was inspired in part by **DBD Perk Slot Machine**, a project by **3stadt**. SanLean's implementation was developed for this project; this credit acknowledges the conceptual inspiration and is not intended to state that 3stadt's source code forms part of the original code developed for SanLean.

Proyecto / Project: https://github.com/3stadt/dbd_perk_slot_machine
