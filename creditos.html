CRÉDITOS

Las ruletas de perks de este sitio fueron desarrolladas específicamente para SanLean. Su concepto y funcionamiento toman como referencia el proyecto DBD Perk Slot Machine — 3stadt, publicado bajo licencia Creative Commons BY-NC-SA 3.0.

La ruleta horizontal de killers fue desarrollada para este sitio tomando como referencia visual y funcional la Ruleta Killer de DBD Takker.

Las Tierlists de este sitio fueron desarrolladas específicamente para SanLean. El sistema de clasificación mediante categorías y arrastre de personajes toma como referencia el concepto popularizado por TierMaker; no se utiliza ni se integra código de TierMaker en estas herramientas.

Parte de los íconos y retratos de Dead by Daylight utilizados en el sitio provienen de las recopilaciones de assets compartidas por DanteASC4 en GitHub, basadas en el paquete de iconos predeterminado de NightLight.

Todo el contenido relacionado con Dead by Daylight —incluidos nombres, íconos, personajes y material del juego— pertenece a Behaviour Interactive y a sus respectivos licenciantes. SanLean es un proyecto de fans independiente y sin fines de lucro.

La imagen de portada / fondo pertenece a Antheia3D.

Si sos autor de alguno de estos contenidos y querés que se modifique, acredite de otra manera o retire algún material, podés contactarme por mail.
