# CARTAS — assets de SanLean

Esta carpeta contiene únicamente las imágenes finales de los resultados de CARTAS en USUARIO.

Los nombres canónicos están definidos en `data/cards-assets.json`. Subir los PNG con esos nombres permite reemplazar los placeholders sin cambiar la lógica del juego.

Recomendación de exportación: PNG, misma relación de aspecto para todas las cartas, transparencia sólo si forma parte del diseño y sin texto dinámico de votos/porcentajes dentro de la imagen.

No mover la lógica de CARTAS a esta carpeta: este directorio es sólo para assets.
