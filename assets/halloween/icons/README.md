# Íconos de Halloween — SanLean

Carpeta destinada a los íconos editados para los mapas interactivos de **Halloween** en la WEB pública.

- Podés subir archivos **PNG, SVG o WebP**.
- **Poneles los nombres que prefieras**. No hay nombres obligatorios ni hace falta renombrarlos para que coincidan con categorías predefinidas.
- Preferentemente usá PNG/WebP con fondo transparente (o SVG propio y seguro), y evitá espacios, tildes o caracteres especiales para simplificar las rutas web.
- Podés subir varios archivos juntos usando **Add file → Upload files** desde GitHub.
- **Todavía no se muestran automáticamente en la web.** Cuando termines de cargarlos, se revisarán sus nombres y se asociarán a las categorías de los mapas en el código de SanLean.
- Asegurate de tener permiso para publicar las imágenes que subas.

No borrar este archivo: permite conservar la carpeta en GitHub cuando no hay imágenes.
